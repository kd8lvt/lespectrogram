# [lespectrogram](https://kd8lvt.github.io/lespectrogram/)
A FOSS web-spectrogram, created for [LesageSinging](https://youtube.com/@LesageSinging) on YouTube.  
Uses the fantastic [Spectrogram-2v02.js](https://www.arc.id.au/Spectrogram.html) library by Dr. A. R. Collins  

# Contributing
We're always open to pull requests! Simply fork the repository and submit a PR when you're ready.
